# /discover-species — 物种发现

你不知道研究哪个物种？让我帮你发现。

## 发现模式

选择一种发现方式：

### 🎲 随机发现
从知识库随机抽取一个物种，给你它的快照：
- 学名 / 中文名 / 科属
- 保护等级 (IUCN + 中国)
- 已知论文数
- 一个有趣的事实

### 🔗 关联发现
从一个你知道的物种出发，发现与之相关的物种：
- 同属近亲
- 同生态位 (竞争/共生)
- 同地理分布
- 同保护等级

### 🏷️ 主题发现
按主题浏览物种库：

| 主题 | 物种数 |
|:-----|:------:|
| 长江旗舰物种 | ~8 |
| 洄游鱼类 | ~6 |
| 濒危物种 (IUCN CR/EN) | ~10 |
| 经济鱼类 | ~12 |
| 入侵物种 | ~4 |

### 🔬 学科跨界
看看一个学科概念如何关联到物种：
- "生态位理论" → 哪些物种是典型案例？
- "生物指示种" → 长江有哪些指示物种？
- "种群连通性" → 哪些洄游鱼类是研究热点？

## 交互流程

```
你: /discover-species
我: 选一个发现模式吧 (随机/关联/主题/学科)
你: 主题
我: 想看什么主题？(长江旗舰物种/洄游鱼类/濒危物种/...)
你: 洄游鱼类
我: 好的！洄游鱼类有：鳤、刀鲚、珠星三块鱼、鲥鱼...
    想深入了解哪个？
你: 珠星三块鱼
我: 快速画像 + 推荐分析路径...
```
