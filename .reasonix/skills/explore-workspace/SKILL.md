# /explore-workspace — 工作空间漫游

你不知道想做什么？没关系。让我帮你发现。

## 第一步：聊聊你的兴趣

先告诉我，今天你想聊什么方向？

你可以说：
- **一个物种名** — "鳤"、"江豚"、"珠星三块鱼"
- **一个主题** — "洄游鱼类"、"保护生物学"、"长江生态"
- **一个问题** — "某个物种为什么濒危"、"研究方法有哪些"
- **完全没想法** — 直接说"不知道"

## 第二步：根据回答推荐路径

根据你的回答，我会推荐几条路径：

### 如果你提到了物种
1. 🔍 **快速画像** → `run_full_analysis.py` — 全自动 Phase 0-5 分析
2. 📚 **文献搜索** → `search_species.py` — 搜索该物种相关论文
3. 🧬 **RCCA 认知分析** → 用 SelfModelEngine 做稳定性检测
4. 🧠 **学科知识图谱** → 在 12 学科中定位该物种的跨学科关联

### 如果你提到了主题
1. 📊 **研究趋势** → `trend_analyzer.py` — 该主题的研究方法学跃迁
2. 🔎 **空白识别** → `gap_analyzer.py` — 未覆盖的研究方向
3. 🔄 **跨物种涌现** → `cross_synthesis.py` — 对比两个物种的相互作用

### 如果你完全没想法
1. 🌊 **物种多样性漫游** — 浏览知识库中的所有物种
2. 📖 **学科拓扑探索** — 从 12 学科的知识图谱出发
3. 🎲 **随机发现** — 随机选一个物种做快速画像

## 第三步：细化

确定了路径后，我会追问具体的参数：
- 物种的中文名和学名？
- 比较的参照物种？
- 输出的格式（文本 / JSON / 可视化）？

然后直接帮你执行。

## 设计原则

- **不问"你想做什么"** — 问"你对什么感兴趣"
- **给选择题不做填空题** — 提供选项而不是空白输入框
- **渐进式聚焦** — 大方向 → 窄领域 → 具体任务
- **可跳过** — 任何时候都可以说"直接做 X"
