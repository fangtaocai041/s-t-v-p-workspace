# 🌌 Cosmic Engine — 宇宙观分析引擎

> *"The universe is a dark forest." Zoom out far enough and every scientific problem
> reveals a pattern you were too close to see.*

---

## PREFLIGHT

Before cosmic zoom, **state the problem in one sentence** at its native scale.
Then define the scale ladder you will climb. Without an anchor, cosmic perspective
becomes cosmic evasion.

---

## CORE OPERATIONS

### 1. COSMIC ZOOM (scale ladder)

```
STEP 0: Problem at native scale (e.g., "One fish species declining in Poyang Lake")
STEP 1: Regional scale     → Same pattern in Dongting? Taihu? Mekong?
STEP 2: Continental scale   → Eurasian freshwater fish trends?
STEP 3: Planetary scale     → Global freshwater biodiversity crisis?
STEP 4: Deep time scale     → Similar collapse in paleontological record?
STEP 5: Cosmic scale        → Is this a universal pattern for resource-limited systems?
STEP 6: RETURN to native    → What changed? What becomes visible/invisible?
```

At each step, ask: **what pattern is visible at this scale that was invisible one
step closer?** The goal is not to escape the problem but to return to it with
new pattern-recognition capabilities.

### 2. DARK FOREST PATTERN DETECTION

> *"Every civilization is a hunter in the dark forest, hiding its existence."* — Liu Cixin

Applied to scientific systems: **when do actors hide signals from each other?**

| Dark Forest Pattern | Scientific Analog | Detection Signal |
|---------------------|-------------------|------------------|
| **Hiding results** | File-drawer effect (unpublished null results) | Meta-analysis funnel plot asymmetry |
| **Concealing capability** | Competitive labs withholding methods | "Methods available upon request" — never fulfilled |
| **Preemptive strike** | Scooping — publish fast to claim priority before rivals | Sudden short-form publications with thin methods |
| **Chain of suspicion** | Peer review hostility to competing paradigms | Reviewer #2 patterns: rejection of all work from rival groups |
| **Broadcast silence** | Data-access restrictions, closed databases | "Data not publicly available" declarations |

When dark forest dynamics are active, the **visible literature is systematically
biased toward safe, positive, non-threatening results**. Adjust certainty downward.

### 3. DIMENSIONALITY ATTACK

> *"A dimension attack destroys a civilization by collapsing its spatial dimensions."*

Applied to analysis: **what if you add or remove a dimension?**

```
2D analysis: species × location (spatial distribution only)
3D analysis: species × location × time (spatiotemporal)
4D analysis: species × location × time × gene flow (spatiotemporal + genetic)
```

For any stuck problem, ask:
- What if I **add** a dimension? (e.g., add genetic data to morphological analysis)
- What if I **remove** a dimension? (e.g., collapse time — does the static snapshot still reveal the pattern?)
- Does the problem **disappear** in one dimension? If so, the problem may be an artifact of dimensional projection.

### 4. UNIVERSAL SOCIOLOGY

> *Axioms of cosmic sociology: (1) Survival is the primary need of civilization.
> (2) Civilization grows but resources are finite.*

Applied to scientific communities: treat research groups as "civilizations"
competing for finite resources (funding, journal space, citation attention).

```
Survival need → grant funding → publish or perish
Resource finiteness → competition → cooperation only when mutually beneficial
Chain of suspicion → cannot trust other groups to share data altruistically
```

When analyzing scientific controversies, universal sociology predicts:
- Groups will **defend their paradigm** (existential threat if paradigm collapses)
- Data-sharing will be **strategic, not altruistic**
- The literature will **underrepresent negative results** (civilizations don't broadcast weakness)

## WHEN → THEN decision rules

```
WHEN stuck on a problem after >3 analytical approaches
  → Apply cosmic zoom (full ladder, Steps 0–6)
  → Identify what is invisible at current scale
  → Return to native scale with at least 1 new pattern insight

WHEN meta-analysis shows funnel plot asymmetry
  → Flag "dark forest: file-drawer effect"
  → Downgrade confidence in published effect sizes
  → Search for unpublished data (preprints, dissertations, conference abstracts)

WHEN two research groups systematically ignore each other's work
  → Flag "dark forest: broadcast silence"
  → Map mutual citation invisibility
  → The ignored group may hold the antithesis (see dialectical-engine)

WHEN a problem resists spatial or temporal analysis alone
  → Apply dimensionality attack: add time, add genetics, add network topology
  → Test: does the pattern survive dimensional expansion?

WHEN analyzing a scientific paradigm under challenge
  → Apply universal sociology axioms
  → Predict: incumbents defend; challengers attack; synthesis is rare without external pressure
  → Use this prediction to calibrate credibility assessments
```
