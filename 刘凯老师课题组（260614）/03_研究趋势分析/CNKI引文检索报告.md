## 四、中文引用网络方法论说明

### 检索使用的途径

| 途径 | 覆盖范围 | 可获取信息 |
|------|---------|-----------|
| 百度学术 | 中文期刊 + 部分学位论文 | 被引次数、施引文献列表 |
| CNKI官网 | 中文期刊全量 | 被引次数、施引文献详情、引用年份分布 |
| 万方数据 | 中文期刊全量 | 被引次数 |
| 期刊官网（Cited-by） | 该刊论文 | 部分施引文献 |
| Bing site:cnki.net | CNKI索引 | 有限 |

### 局限性

1. **CNKI付费墙**: 无法直接获取完整的施引文献列表
2. **百度学术数据**: 被引次数可能包含自引和重复计数
3. **学位论文引用**: 未纳入统计
4. **会议论文引用**: 未纳入统计

### 改进建议

如果使用CNKI机构订阅账号，可：
1. 获取每篇论文的**完整施引文献列表**
2. 生成**引用年份分布图**（分析引用趋势）
3. 识别**高被引论文的引用主题聚类**
4. 计算**H指数的中文贡献部分**
