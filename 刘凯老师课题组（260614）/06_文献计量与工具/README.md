## 四、研究主题演变

| 时期 | 主导主题 | 方法特征 |
|------|---------|---------|
| 2004—2010 | 渔业资源调查、刀鲚基础生物学 | 传统网具+生物学测量 |
| 2011—2019 | 刀鲚生态、江豚保护起步、分子遗传 | RAPD/SSR+mtDNA+RNA-seq |
| 2020—2026 | **T2T基因组·禁渔评估·微生物组·免疫** | T2T+群体基因组+eDNA+多组学 |

**当前六大核心方向**（2020—2026）：
1. 禁渔评估（鱼类+虾类+浮游+底栖全维度）
2. T2T比较基因组学（10+物种）
3. 刀鲚保护生物学（基因组+群体遗传+微生物组）
4. 长江江豚保护（基因组+迁地保护+救护）
5. 病害生态学（🌟新兴：蟹奴+异尖线虫）
6. 鱼类早期资源与增殖管理
