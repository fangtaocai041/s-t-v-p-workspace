# Zotero 共享文献库 — 刘凯课题组

> 本文件包含 BibTeX 格式的参考文献导出数据
> 导入方法: Zotero → File → Import → BibTeX (.bib)

---

## 导入步骤

1. 在 Zotero 中创建群组：File → New Group → 创建"刘凯课题组"（建议 Private / Membership by invitation）
2. 点击 File → Import → 选择 `liukai_group.bib`
3. 所有57+篇PubMed论文 + 172篇中文论文自动导入
4. 设置自动同步：Zotero Preferences → Sync → 登录 Zotero账号
5. 课题组每位成员安装 Zotero 浏览器插件（Zotero Connector），可直接从期刊网页一键添加新论文

## 共享方案选项

| 方案 | 优点 | 缺点 |
|------|------|------|
| **Zotero Groups（推荐）** | 免费、自动同步、Web版可查 | 群组存储空间300MB |
| **Zotero + WebDAV** | 更大存储空间 | 需自行配置 |
| **本地BibTeX + Git** | 可版本控制 | 需手动合并 |
